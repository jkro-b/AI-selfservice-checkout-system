
# AI-selfservice-checkout-system
## Summary
Everyone nowadays uses self-service checkout. I am personally sometimes tired of scanning items myself, but also don´t want to wait in the line for normal checkout. So what if the checkout was done by the cash register? My idea is that the cash register would scan the items by himself, you will just need to put your groceries in the area where you normally do.

### What data should it use?
I was thinking about the openfoodfacts API, but that was at the beginning. Now I have an internal database on my mind. To be honest, there are two possible ways. Firstly doing it simply by the bar codes on the groceries (must think about the fruit, vegetables, pastry and also about positioning of the bar codes). Secondly, doing it through image recognition, where the input would be images from different sizes.

### How it is used?
I think it has potential in speeding up the process of buying things. From which can benefit the customer and also the shopkeeper.

###  Challenges
As I said earlier, the fruit and vegetable could be a problem, but solvable. Also with the bar code approach, could be a real challenge the customer putting it on the scale. We cannot predict the positioning of the bar code and also if the bar code is hidden during the scanning procedure.

### What´s next?
Maybe it could grow in the self service market, which is already sometimes in use.
